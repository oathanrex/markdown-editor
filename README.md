## 🚀 Overview

Markdown Editor is a completely browser-based text editor built for developers, writers, and students. It combines the simplicity of writing in Markdown with powerful advanced features.

The best part? **Your data never leaves your device.** There is no backend, no analytics, and absolutely no tracking.

## ✨ Key Features

*   **⚡ Real-time Markdown preview:** See your formatting instantly as you type.
*   **🛠️ GitHub Flavored Markdown (GFM):** Fully supports tables, task lists, and strikethroughs.
*   **📐 Advanced Rendering:** Built-in LaTeX math rendering and Mermaid diagrams.
*   **🎨 Syntax highlighting:** Beautiful code blocks for your programming snippets.
*   **🌐 Works fully offline (PWA):** Install it on your device and use it anywhere without the internet.
*   **🔒 Absolute Privacy:** No sign-up, no tracking.

## 💻 Tech Stack

*   **Frontend Core:** HTML, CSS, JavaScript.
*   **Architecture:** 100% client-side.
*   **Storage Mechanism:** Local storage only.

## 💼 Why I Built This
I built this tool to create a distraction-free, privacy-focused environment for formatting technical documents. It serves as a highly practical utility while showcasing modern web development techniques without relying on heavy frameworks.
